# Keyboard and Mouse

## Project

| Keys | Action |
|---|---|
| ++ctrl+n++ | New project |
| ++ctrl+o++ | Open project |
| ++ctrl+s++ | Save project |
| ++ctrl+w++ | Close project |
| ++ctrl+q++ | Exit |

## Steps

| Key | Step |
|---|---|
| ++i++ | 1 Import |
| ++e++ | 2 Split Pages |
| ++n++ | 3 Deskew |
| ++v++ | 4 Select Content |
| ++k++ | 5 Margins |
| ++p++ | 6 Output |
| ++f5++ | Reload the current page |

## Pages

| Keys | Action |
|---|---|
| ++page-down++ or ++w++ | Next page |
| ++page-up++ or ++q++ | Previous page |
| ++shift+page-down++ or ++shift+w++ | Next selected page |
| ++shift+page-up++ or ++shift+q++ | Previous selected page |
| ++home++ / ++end++ | First / last page |
| ++ctrl+g++ | Go to page |
| ++ctrl+plus++ / ++ctrl+minus++ | Larger / smaller thumbnails |
| ++alt++ + mouse wheel | Scale the thumbnails |
| ++ctrl++ + click, ++shift++ + click | Select several pages |

## Page view

| Input | Action |
|---|---|
| Mouse wheel, ++plus++ / ++minus++ | Zoom |
| Drag | Move the zoomed page |
| Double-click | Show the whole page (not in *Select Content* and *Margins*) |
| ++shift++ while dragging | Unrestricted dragging |

## Deskew

| Input | Action |
|---|---|
| Drag a handle | Rotate, or adjust the oblique angle |
| ++ctrl++ + mouse wheel | Rotate |
| ++ctrl+shift++ + mouse wheel | Rotate in finer steps |

## Select Content

| Input | Action |
|---|---|
| Drag a side or corner | Resize the box |
| ++shift++ + drag | Move the box |
| Double-click on content | Fit the content box to it |
| Right click | Create or remove the content box |

## Margins

| Input | Action |
|---|---|
| Drag a solid line | Change a margin |
| Right click | Add or remove guides; show the hard margins rectangle |
| ++ctrl+alt++ + drag | Move the guide under the mouse |
| ++shift++ / ++ctrl++ + drag on the content | Move the content horizontally / vertically (both: freely) |
| Double-click on content | Attach it to the nearest guide |

## Output

| Keys | Action |
|---|---|
| ++ctrl+1++ … ++ctrl+5++ | Tabs *Output*, *Picture Zones*, *Fill Zones*, *Dewarping*, *Despeckling* |

### Zone editors (Picture Zones, Fill Zones)

| Input | Action |
|---|---|
| ++z++ / ++x++ / ++c++ | Polygon / lasso / rectangle selection for new zones |
| Click | Start a new zone; with the polygon, add a corner |
| Click the first corner | Close a polygon zone |
| ++escape++ | Cancel the zone being drawn |
| Drag a corner | Move it; hold ++ctrl++ for a right angle |
| ++d++ over a corner | Delete the corner |
| ++shift++ + drag | Move the zone |
| ++shift+ctrl++ + drag | Copy the zone |
| ++ctrl+alt++ + click | Copy the zone created last |
| ++delete++ | Delete the zone under the mouse |
| Right click on a zone | Properties, delete |

### Dewarping curves (method *Manual*)

| Input | Action |
|---|---|
| Click on a curve | Add a control point |
| Drag a point | Move it; ++ctrl++ or ++shift++ along an axis |
| ++d++ over a point | Delete it |
