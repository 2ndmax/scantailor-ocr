*[DPI]: Dots per inch: how many pixels of the scan fall on one inch of paper.
*[PDF/A-2b]: An ISO standard for PDF files meant for long-term archiving.
*[JBIG2]: A lossless compression for black and white images, used inside PDF files.
*[CCITT G4]: An older lossless compression for black and white images, known from fax.
*[hOCR]: An HTML format for recognized text with the position of each word.
*[ALTO]: An XML format for recognized text with the position of each word, used by libraries and archives.
*[MCP]: Model Context Protocol: a way for AI agents to use tools.
